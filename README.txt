KOPI KALA - WEBSITE KATALOG KOPI

CARA MENJALANKAN:
1. Ekstrak file KOPI_KALA.zip.
2. Buka folder KOPI_KALA menggunakan Visual Studio Code.
3. Pastikan file index.html, style.css, dan script.js berada dalam satu folder.
4. Klik kanan index.html lalu pilih "Open with Live Server" (jika ekstensi Live Server sudah terpasang).
   Alternatif: klik dua kali file index.html untuk membukanya di browser.

FITUR:
- Navigasi responsif untuk desktop dan HP.
- Dark mode / light mode.
- Filter kategori menu kopi.
- Slider galeri otomatis dan tombol navigasi.
- Modal detail produk.
- Validasi form kontak.

CATATAN:
- Foto menggunakan URL Unsplash, sehingga koneksi internet diperlukan agar gambar tampil.
- Font Google Fonts dan ikon Font Awesome juga memerlukan internet.
- Nama alamat, nomor telepon, email, dan harga merupakan data contoh untuk tugas.
- Form kontak hanya simulasi front-end; belum mengirim pesan ke email atau database.
